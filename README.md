# BionicPRO

BionicPRO — система доступа и отчётности для пользователей бионических протезов.
Личный кабинет показывает показатели только собственных протезов и позволяет
скачать отчёт за завершённые дни. Распознавание движений работает на чипе
протеза и не зависит от доступности отчётности.

## Архитектура

React обращается через HTTPS-шлюз Nginx к `bionicpro-auth` — серверной части
интерфейса (BFF). BFF выполняет вход через Keycloak, хранит токены на сервере
и выдаёт браузеру защищённую сессионную cookie. Keycloak объединяет локальные
учётные записи, OpenLDAP и настраиваемый вход через Яндекс ID; вход требует
одноразового кода.

Изменения PostgreSQL CRM и телеметрии поступают через Debezium и Kafka в
ClickHouse. Этот механизм CDC (Change Data Capture) заменяет регулярную
массовую выгрузку источников. ClickHouse объединяет данные и рассчитывает
показатели, Airflow каждую минуту публикует готовые версии дней и каталог
версий в MinIO. API на Go проверяет пользователя и формирует JSON из витрины
только при отсутствии файла в S3. Повторные запросы используют сохранённый
файл; Nginx имитирует CDN — кеш доставки файлов — и проверяет доступ при
каждом скачивании.

Все компоненты локального стенда моделируют один региональный контур.
Источники содержат синтетические данные. Региональное размещение, интеграция
с реальными CRM/датчиками и отказоустойчивость описаны как ограничения и
дальнейшие решения в архитектурных документах.

## Быстрый запуск

Нужны Docker с Compose v2, Python 3.12+, OpenSSL и сеть для первой сборки.
Из корня репозитория:

```bash
python3 scripts/prepare-local.py
docker compose build minio
docker compose build minio-init
docker compose up -d --build
```

После готовности сервисов откройте `https://localhost:3443`.
Учебный вход: `user1` / `password123`, затем настройка одноразового кода.
Подготовка сохраняет секреты в локальном `.env`; для внешнего Яндекс ID
нужны реквизиты собственного OAuth-приложения.

Подробности: [запуск, демоданные, получение отчётов и общие проверки](operations.md),
[сертификат, первый вход и Яндекс ID](Task1/authentication.md).
