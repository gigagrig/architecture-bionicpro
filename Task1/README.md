# Доступ и учётные записи BionicPRO

Система предоставляет единый вход в личный кабинет для локальных пользователей,
сотрудников из LDAP-каталога и пользователей внешнего Яндекс ID.
Каждое представительство имеет собственный контур учётных записей и данных;
локальный стенд моделирует один такой контур.

## Устройство и решения

- React обращается к `bionicpro-auth` — серверной части интерфейса (BFF).
  BFF выполняет обмен кода с Keycloak с защитой PKCE S256 от использования
  перехваченного кода; токены доступа и обновления остаются на сервере.
- Браузер получает cookie с флагами HttpOnly и Secure. BFF обновляет токен
  доступа и меняет идентификатор сессии при защищённых запросах. Токен доступа
  живёт 120 секунд, сессия — до 30 минут бездействия и не более 8 часов.
- Keycloak проверяет локальные пароли или обращается в OpenLDAP по LDAPS.
  Роли каталогов приводятся к общим названиям. Сервис, выдающий данные протеза,
  отдельно проверяет его принадлежность пользователю.
- Одноразовый код обязателен после основного входа, включая внешний IdP —
  службу подтверждения личности. Профиль Яндекса сохраняется в зашифрованном
  виде только после отдельного согласия пользователя.

Сессии находятся в памяти одного BFF: перезапуск завершает их, а несколько
экземпляров требуют общего хранилища. Яндекс ID выключен до настройки
реквизитов приложения. Нативные мобильные клиенты в репозитории отсутствуют.

## Запуск и настройка

Запустите общий стенд по [корневому README](../README.md#быстрый-запуск).
Адрес: `https://localhost:3443`; учебный вход: `user1` / `password123`,
затем настройка одноразового кода.

[Настройка авторизации](authentication.md): сертификат, учебные аккаунты,
OTP, Яндекс ID, экспорт Keycloak и проверки сессии.
