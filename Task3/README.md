# Хранение и доставка отчётов BionicPRO

Готовые JSON-отчёты сохраняются в закрытом MinIO, совместимом с объектным
хранилищем S3. Nginx имитирует CDN — кеш доставки файлов. Повторный запрос
того же владельца, периода и версии обходится без чтения ClickHouse.

## Устройство и решения

1. API на Go проверяет пользователя, читает каталог опубликованных версий
   в S3 и вычисляет путь отчёта по владельцу, периоду и версиям дней.
2. Если файл отсутствует, API читает готовые строки ClickHouse и сохраняет
   JSON в S3. Если файл есть, сразу возвращает временную ссылку.
3. Nginx выдаёт файл из кеша либо загружает его из S3. При каждом скачивании,
   включая попадание в кеш, BFF (серверная часть интерфейса) и API проверяют
   сессию, владельца, подпись и срок ссылки. Ссылка действует пять минут.
4. Изменение данных создаёт новую версию и новый путь файла. Старая ссылка
   сохраняет прежний снимок до истечения срока; браузер не хранит отчёт
   в дисковом кеше.

Airflow публикует действующий каталог `catalog/cdc-current.json` после
готовности CDC-витрины. Старые файлы сохраняются: регламент очистки S3,
ClickHouse и CDN требует отдельного решения. Локальные MinIO и CDN
работают по одному экземпляру, без промышленного резервирования.

[Архитектура и схема](architecture.md), [Go API](../reports-api/cache.go),
[конфигурация CDN](../nginx/cdn.conf).

## Запуск и использование

MinIO и CDN входят в [общий стенд](../README.md#быстрый-запуск).
После [публикации демоданных](../Task4/operations.md#демоданные-и-публикация-периода)
откройте `https://localhost:3443` и получите отчёт. Повтор того же периода
использует сохранённую версию, пока её исходные дни не изменились.

Обновление стенда и проверки кеша — в [руководстве](operations.md).
Результаты проверок — в [report.md](../report.md).
